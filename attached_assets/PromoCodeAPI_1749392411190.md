
# API Blueprint – The Pot Promo Code System

## POST /promo-code/generate

**Description:** Generate a promo code for a Personal or Group Pot.

**Request Body:**
```json
{
  "userId": "string",
  "potId": "string",
  "potType": "PP | GP",
  "userBalance": "number",
  "potGoalStatus": "GOAL_MET | NOT_MET"
}
```

**Response:**
```json
{
  "promoCode": "THEPOT-PP-123456",
  "status": "success"
}
```

---

## POST /promo-code/verify

**Description:** Verify a promo code from a merchant's system.

**Request Body:**
```json
{
  "promoCode": "THEPOT-PP-123456"
}
```

**Response:**
```json
{
  "status": "valid | used | invalid",
  "potId": "string",
  "potType": "PP | GP",
  "encryptedKey": "base64string"
}
```

---

## POST /promo-code/flag-reuse

**Description:** Report a reused promo code and restrict the user's permissions.

**Request Body:**
```json
{
  "userId": "string",
  "promoCode": "string"
}
```

**Response:**
```json
{
  "userId": "string",
  "restrictions": ["no-pot-creation"],
  "supportTicketGenerated": true
}
```
